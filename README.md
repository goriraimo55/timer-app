# 技術者ギルド | Kosen Quest Platform

高専生向けの「技術クエスト型学習・仕事マッチングWebアプリ」のプロトタイプです。

企業が投稿する小さな技術課題を「クエスト」として提示し、高専生がゲーム感覚で挑戦しながら経験値・スキルを積み、学習コンテンツで基礎を固め、実績をそのまま就活用ポートフォリオ(スキル証明書)に変換できることを目指しています。教員が安全性・妥当性を確認するフローと、企業⇄学生の相互評価によってブラック案件を防止する仕組みも組み込んでいます。

> このアプリの本質は「企業の小さな技術課題」を「高専生の成長クエスト」に変換することです。

## コンセプト

- Duolingoのように毎日続けたくなる(連続学習日数・デイリークエスト・レベルアップ演出)
- GitHubのように実績が残る(クエスト・教材の完了履歴がそのままポートフォリオに)
- クラウドワークスのように企業が仕事を投稿できる(テンプレート入力フォーム)
- RPGのように経験値・レベル・称号・スキルツリーがある
- 教員が安全性・難易度・守秘義務を確認できる(承認・差し戻し・却下フロー)
- 就活やインターンに使える実績証明が残る(スキル証明書PDF/印刷出力)

## 技術構成

- [Next.js 16](https://nextjs.org/)(App Router) + TypeScript
- Tailwind CSS v4
- shadcn/ui 相当の自作UIコンポーネント(Radix UI プリミティブ + class-variance-authority)
  - ネットワーク制限により `shadcn` CLI(`ui.shadcn.com`)が利用できない環境だったため、同じ設計思想(Radix + cva + tailwind-merge)で `src/components/ui/` 配下に手動実装しています。
- `localStorage` によるデータ永続化(バックエンド・DB・ログイン機能なし)
- レスポンシブ対応・日本語UI・ダークモード基調のネオン/技術者ギルド風デザイン

## 起動方法

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

その他のコマンド:

```bash
npm run build     # 静的サイトとして out/ にビルド(output: "export")
npx serve out     # ビルド結果をローカルで確認
npm run lint      # ESLint
```

## GitHub Pages で公開する(ブラウザで動かす)

このアプリは静的書き出し(`output: "export"`)に対応しており、GitHub Pages 上でそのまま動きます。`main` ブランチへのプッシュで `.github/workflows/deploy-pages.yml` が自動的にビルド&デプロイします。

**初回のみ必要な設定:**

1. GitHubのリポジトリページで **Settings → Pages** を開く
2. **Source** を **GitHub Actions** に変更する(「Deploy from a branch」のままだとREADMEやソースがそのまま表示されてしまいます)
3. **Actions** タブからワークフロー「Deploy to GitHub Pages」が成功するのを待つ

公開URL: `https://<ユーザー名>.github.io/timer-app/`

(バックエンド不要・全データ`localStorage`保存のため、静的ホスティングだけで全機能が動作します)

初回アクセス時は、デモ用にあらかじめ経験値・完了クエスト・バッジなどが入った状態(Lv.5・XP1,450・連続学習8日など)から始まります。挑戦・学習・投稿・承認などの操作はすべてブラウザの `localStorage`(キー: `kosen-quest-state-v1`)に保存されます。リセットしたい場合はブラウザの開発者ツールから該当キーを削除してください。

## 実装済み機能一覧

### 画面(全13種類)
1. ホーム画面 — レベル/XP/連続学習日数/バッジ/おすすめクエスト・教材/週間ランキング/デイリークエスト/広告
2. クエスト一覧画面 — キーワード・カテゴリ・難易度・リモート可否での絞り込み、承認状態バッジ
3. クエスト詳細画面 — 背景/依頼内容/成果物/危険度ラベル/評価基準/提出テンプレート連携/提出ダイアログ
4. 企業向け仕事投稿テンプレート画面 — 全項目入力フォーム、送信後は「教員承認待ち」でクエスト一覧に反映
5. 機械設計学習ページ — 10カテゴリ・教材15件、ミニクイズ、学習完了でXP付与
6. スキルツリー画面 — スキル10種、クエスト・教材完了でスキルXPが伸びる
7. プロフィール画面 — 実績ポートフォリオ、企業評価/学生評価、名前などの編集
8. 教員承認画面 — 承認待ち一覧、教員コメント、承認/差し戻し/却下(承認済みのみ挑戦可能になる)
9. 成果物提出テンプレート画面 — テンプレート8件(使用目的・記入項目・提出形式・評価ポイント・サンプル)
10. 企業評価・学生評価画面 — 相互評価一覧、完了クエストに対する学生→企業評価フォーム
11. スキル証明書PDF出力画面 — 印刷用レイアウト、`window.print()` によるPDF出力
12. チームクエスト画面 — 一覧・詳細、役割選択して参加申請
13. 広告枠 — ホーム/クエスト一覧/クエスト詳細/学習/チームクエストに配置(ダミー広告6件)

### ゲーミフィケーション
- 経験値・レベルアップ(300XPごとにレベルアップ、称号が変化)
- 連続学習日数(日をまたぐと自動加算、リセット判定つき)
- バッジ10種(条件を満たすと自動付与、プロフィール/証明書に反映)
- 週間ランキング(8人分のダミーデータ)
- デイリークエスト・レアクエストのラベル表示
- スキルツリー(10スキル、レベル・進捗バー表示)
- 称号(レベルに応じて自動変化)
- 学習完了・クエスト完了アニメーション(紙吹雪 + トースト演出)
- チームクエスト・教員承認済みバッジ・企業評価バッジ

### データ永続化・連携ロジック(localStorage)
- 総経験値・レベル・連続学習日数・バッジ
- 企業フォームから追加したクエスト(初期状態は「承認待ち」)
- 教員による承認ステータスの上書き(承認済みのみ学生側で「挑戦する」が有効化)
- 完了した教材・完了したクエスト、スキルごとの経験値
- チームクエストへの参加申請
- 学生から企業への評価投稿

### ダミーデータ(最低件数を充足)
クエスト15件(うち5件は承認待ち) / 学習教材15件 / バッジ10件 / 広告6件 / ランキング8人分 / スキル10種類 / チームクエスト5件 / 提出テンプレート8件 / 企業評価データ5件

## 動作確認

Playwrightによる主要フローの自動確認(クエスト挑戦→XP増加→演出表示、学習完了、企業投稿→教員承認→挑戦可能化、チーム参加申請、証明書表示 等)と `npm run build` / `npm run lint` / `tsc --noEmit` によるビルド・型チェックを実施済みです。
